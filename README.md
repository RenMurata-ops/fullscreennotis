# フルスクリーン通知ツール (Webアプリ版)

決まった日時にPC画面全体にフルスクリーン通知を表示するWebアプリケーションです。

## 特徴

- 📅 日時を指定してスケジュール登録
- 📱 フルスクリーンで通知を表示（Fullscreen API使用）
- 🔔 1回だけ実行（実行後は自動削除）
- 💬 カスタムメッセージの設定
- ⏰ 60秒後に自動的に閉じる
- ✨ 美しいグラデーションUI
- 🌐 ブラウザで動作（インストール不要）
- 💾 localStorage でデータを保存

## セットアップ

### 必要な環境

- モダンなWebブラウザ（Chrome、Firefox、Edge、Safari など）
- ローカルサーバー（開発用）

### 起動方法

#### 方法1: Python を使用（推奨）

```bash
# Python 3がインストールされている場合
npm start
# または
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` にアクセスします。

#### 方法2: 他のローカルサーバーを使用

```bash
# Node.js の http-server を使用
npx http-server -p 8000

# PHP を使用
php -S localhost:8000
```

#### 方法3: 直接HTMLファイルを開く

セキュリティ制約により、一部のブラウザでは `file://` プロトコルでの動作が制限される場合がありますが、
基本的な機能は動作します。

## 使い方

### 1. アプリケーションを開く

ブラウザで `index.html` を開きます（ローカルサーバー経由を推奨）。

### 2. 通知のスケジュール設定

1. 「日時」フィールドで通知を表示したい日時を選択
2. 「メッセージ」フィールドに表示したいメッセージを入力
3. 「スケジュールを追加」ボタンをクリック

### 3. 通知の表示

- **重要**: ページを開いたままにしておく必要があります
- スケジュールした日時になると、自動的に通知ページに遷移します
- 「フルスクリーンで表示」ボタンでフルスクリーン表示できます
- 通知は以下の方法で閉じることができます：
  - 「閉じる」ボタンをクリック
  - ESCキーを押す（フルスクリーン時はフルスクリーン解除のみ）
  - 60秒間放置（自動的に閉じます）

### 4. スケジュールの管理

- 予定されている通知は画面下部のリストに表示されます
- 「削除」ボタンで不要なスケジュールを削除できます
- 一度表示された通知は自動的にスケジュールから削除されます

## 技術仕様

- **フロントエンド**: Vanilla JavaScript（フレームワーク不使用）
- **データ保存**: localStorage
- **フルスクリーン**: Fullscreen API
- **スケジュールチェック**: setInterval（10秒ごと）
- **自動クローズ**: 60秒

## 重要な注意事項

### ⚠️ ページを開いたままにする必要があります

このWebアプリケーションは、**ページを開いている間のみ動作します**。

- ページを閉じると、スケジュールされた通知は表示されません
- ブラウザを閉じると、通知機能は停止します
- コンピューターがスリープ状態になると、通知は表示されません

### 💡 推奨される使用方法

1. 専用のブラウザウィンドウまたはタブで開く
2. ブラウザをバックグラウンドで起動したままにする
3. 重要な通知の場合は、通知時刻の前にページが開いていることを確認する

### 🔒 データの保存場所

- スケジュールデータは**ブラウザのlocalStorage**に保存されます
- ブラウザのキャッシュをクリアすると、データが削除されます
- 異なるブラウザやプライベートモードでは、データは共有されません

## ブラウザ互換性

- Chrome/Edge: ✅ 完全サポート
- Firefox: ✅ 完全サポート
- Safari: ✅ 完全サポート
- モバイルブラウザ: ⚠️ フルスクリーンAPIの制限あり

## トラブルシューティング

### フルスクリーンが機能しない

- ブラウザの設定でフルスクリーンが許可されているか確認してください
- ユーザー操作（ボタンクリック）が必要です（自動では起動できません）

### 通知が表示されない

- ページが開いたままになっているか確認してください
- ブラウザのコンソールでエラーが出ていないか確認してください
- localStorageが有効になっているか確認してください

### スケジュールが消えた

- ブラウザのキャッシュをクリアしていないか確認してください
- 同じブラウザで開いているか確認してください（プライベートモードは別扱い）
