# フルスクリーン通知ツール

決まった日時にPC画面全体にフルスクリーン通知を表示するElectronアプリケーションです。

## 機能

- 📅 日時を指定してスケジュール登録
- 📱 フルスクリーンで通知を表示
- 🔔 1回だけ実行（実行後は自動削除）
- 💬 カスタムメッセージの設定
- ⏰ 60秒後に自動的に閉じる
- ✨ 美しいグラデーションUI

## セットアップ

### 必要な環境

- Node.js（v14以上推奨）
- npm

### インストール

```bash
# 依存パッケージのインストール
npm install
```

## 使い方

### アプリケーションの起動

```bash
# 起動
npm start
```

### 通知のスケジュール設定

1. アプリケーションを起動すると設定画面が表示されます
2. 「日時」フィールドで通知を表示したい日時を選択
3. 「メッセージ」フィールドに表示したいメッセージを入力
4. 「スケジュールを追加」ボタンをクリック

### 通知の表示

- スケジュールした日時になると、自動的にフルスクリーン通知が表示されます
- 通知は以下の方法で閉じることができます：
  - 「閉じる」ボタンをクリック
  - ESCキーを押す
  - 画面をクリック
  - 60秒間放置（自動的に閉じます）

### スケジュールの管理

- 予定されている通知は画面下部のリストに表示されます
- 「削除」ボタンで不要なスケジュールを削除できます
- 一度表示された通知は自動的にスケジュールから削除されます

## 技術仕様

- **フレームワーク**: Electron
- **スケジュール保存**: JSON形式（userData/schedules.json）
- **チェック間隔**: 10秒ごと
- **自動クローズ**: 60秒

## ファイル構成

```
fullscreennotis/
├── main.js              # メインプロセス（Electron）
├── index.html           # 設定画面
├── notification.html    # フルスクリーン通知画面
├── package.json         # プロジェクト設定
└── README.md           # このファイル
```

## 注意事項

- アプリケーションが起動していない場合、スケジュールされた通知は表示されません
- システム起動時に自動起動したい場合は、OSの自動起動設定が必要です
- 通知は実行後、自動的にスケジュールから削除されます（1回のみ実行）
